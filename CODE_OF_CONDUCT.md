# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and respectful environment for all contributors and users of COBOL Coroner, regardless of experience level, background, or identity.

## Expected Behavior

- Use welcoming and inclusive language
- Be respectful of differing viewpoints and experiences
- Accept constructive criticism gracefully
- Focus on what is best for the community and the project
- Show empathy towards other community members

## Unacceptable Behavior

- Harassment, intimidation, or discrimination in any form
- Offensive comments related to personal characteristics
- Unwelcome sexual attention or advances
- Trolling, insulting comments, or personal attacks
- Public or private harassment
- Publishing others' private information without permission
- Other conduct that could reasonably be considered inappropriate in a professional setting

## Enforcement

Violations of this code of conduct should be reported to the repository owner through GitHub:

- For security matters: use GitHub private vulnerability reporting (Security tab, "Report a vulnerability")
- For other matters: open a GitHub issue

All reports will be reviewed and investigated. The repository owner will respond appropriately, which may include warnings or removal from the project.

## Scope

This code of conduct applies to all project spaces, including the repository, issue tracker, and any other forum where COBOL Coroner is discussed.

## Attribution

This code of conduct is inspired by community standards for open source projects.
