# Screenshots requirements

## Context
D-58: README screenshots like a product page: a 10 to 15 s GIF under 5 MB at the top (Run audit on T1 faulty, the ZOMBIE badge, the minimal-case example), then the T1 ZOMBIE page (dark), an ALIVE page (light), the Detection Matrix, Tamper giving INVALID and the terminal with the commit blocked by Coroner. All from real runs, generated by `make screenshots` (Playwright) into docs/screenshots/ as optimized PNGs, each with alt text and a one-line caption, no home path, no private data, nothing typed by hand; regenerated after the last UI change before the freeze; reused by the static page and the gallery.

## Requirements

### 1. Dependencies
**Req 1.1**: New optional extra in pyproject.toml: `screenshots = ["playwright==1.64.1", "pillow==13.0.0"]`.
**Req 1.2**: playwright is Apache-2.0, Pillow is MIT-CMU (check installed package metadata).
**Req 1.3**: README "Third-party components" gains both dependencies with licenses and a note that `python -m playwright install chromium` downloads a browser not part of the repository.
**Req 1.4**: Neither dependency is added to the Docker image or other extras.

### 2. Screenshot generation script
**Req 2.1**: scripts/make_screenshots.py generates all screenshots from real runs.
**Req 2.2**: Makefile target `screenshots:` runs `$(PYTHON) scripts/make_screenshots.py`.
**Req 2.3**: The script uses a temporary CORONER_BASE_DIR, never the repository's runs/.
**Req 2.4**: Produces REAL runs with the engine: T1 faulty (ZOMBIE, 2000 cases, seed 42), T1 correct (ALIVE, 2000 cases, seed 42), and the trap catalog (runs/trap_catalog.json).
**Req 2.5**: Starts the real UI (uvicorn coroner.ui.app) on 127.0.0.1 with a free port and the temp base dir.
**Req 2.6**: Drives headless Chromium with Playwright, viewport 1280x800, device scale 1.
**Req 2.7**: Never prints a home directory path, a temporary directory path or the clone path.

### 3. Generated images
**Req 3.1**: docs/screenshots/t1-zombie-dark.png: T1 faulty run page, dark theme, full first screen only.
**Req 3.2**: docs/screenshots/alive-light.png: T1 correct run page, light theme (via localStorage key coronerTheme), full first screen only.
**Req 3.3**: docs/screenshots/matrix.png: Detection Matrix page, full first screen only.
**Req 3.4**: docs/screenshots/verify-invalid.png: the real Tamper flow on the T1 faulty run (same steps as video shot 14): /tamper?run_id=<run id>, Status set to ALIVE, Cases Divergent set to 0, "Verify Tampered Certificate" clicked, 1280x800 view showing the edited form and "Certificate: INVALID" with its reason; caption names the run id and the edited values.
**Req 3.5**: docs/screenshots/commit-blocked.png: terminal screenshot showing blocked commit.
**Req 3.6**: docs/screenshots/demo.gif: 10 to 15 s, under 5 MB, width 960, reduced palette, duplicate frames merged.
**Req 3.7**: All PNGs saved with Pillow optimize=True.

### 4. Commit blocked screenshot
**Req 4.1**: Temporary clone of the repository (git clone --local of HEAD), hooks path .githooks.
**Req 4.2**: Replace audited Java (from .kiro/coroner-scope.json) with HALF_EVEN variant.
**Req 4.3**: Stage the file and run `git commit -m "Port credit fees"`, capture output and exit code.
**Req 4.4**: Exit code must be non-zero, else fail the script.
**Req 4.5**: Replace temp clone path by "repo" and fail if output still contains home directory paths, temporary directory paths or the temp clone path.
**Req 4.6**: Render as plain dark terminal-like HTML page (monospace, prompt line, captured output verbatim, no window chrome).

### 5. Demo GIF
**Req 5.1**: 10 to 15 s duration, fail if shorter than 10 s.
**Req 5.2**: Navigate from "/" to T1 faulty run page, badge animation visible.
**Req 5.3**: Pause on verdict sentence and minimal-case example.
**Req 5.4**: Scroll to branch chart.
**Req 5.5**: Capture frames at about 8 fps with page.screenshot.
**Req 5.6**: Build GIF with Pillow, reduced palette, duplicate frames merged, width 960.
**Req 5.7**: Fail if GIF is 5 MB or more.

### 6. README integration
**Req 6.1**: demo.gif right under the title/intro.
**Req 6.2**: "Screenshots" section with five PNGs.
**Req 6.3**: Each image has alt text and a one-line caption stating only what the image shows.
**Req 6.4**: No numbers typed by hand in captions.
**Req 6.5**: Note that images are produced by `make screenshots` from real runs.

### 7. Static tests
**Req 7.1**: tests/test_screenshots_static.py checks every image referenced from README under docs/screenshots/ exists.
**Req 7.2**: Each has non-empty alt text.
**Req 7.3**: demo.gif is under 5 MB.
**Req 7.4**: scripts/make_screenshots.py contains no hardcoded verdict numbers.
**Req 7.5**: No test runs the browser in the default suite.

### 8. Script output
**Req 8.1**: Script prints each output file with its size.
**Req 8.2**: Stops the server, deletes temp base dir and clone.
**Req 8.3**: Never prints home paths.
