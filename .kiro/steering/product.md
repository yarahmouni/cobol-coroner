# Product

COBOL Lazarus is "the zombie detector for COBOL to Java migrations".

- Lazarus verifies a migration provided by the user. It never converts code.
- Rule: "AI accelerates, Lazarus certifies." The VIVANT/ZOMBIE verdict is always deterministic and never depends on an AI model.
- Audience: banks and teams modernizing COBOL batch programs.
- Hackathon: Kiroween 2026, category Resurrection.
- All user-facing text, code comments and docs are in English.
- Never use the em dash character in any file.
- Every decision is logged in `docs/decisions.md`.
